# 06 — 测试与验收策略

- 版本：v0.1
- 日期：2026-11-21
- 状态：草案

## 1. 原则

- 核心逻辑不依赖真实窗口；状态机用纯单元测试。
- 真实捕获、权限、窗口切换必须手工/集成验证，不用 mock 冒充。
- 测试不得请求真实 AI 服务、不得上传屏幕内容、不得写入用户对话。
- 任何“完成检测通过”的结论必须附 fixture 或人工标注记录。

## 2. 测试层级

| 层级 | 范围 | 工具/方式 | 何时跑 |
|---|---|---|---|
| Unit | `ReplyCompletionDetector`、模型、Profile 解析 | `swift test` | 每次提交 |
| Contract | `CaptureSource` / `WindowActivating` / `PermissionManager` 协议 | mock 注入 | 每次提交 |
| Integration | 单窗口真实捕获、帧回调、缩略图 | 本地手工 + 脚本 | M1 起 |
| Manual UI | 多卡片、点击切换、权限、浅/深色、窄窗口 | 人工 | M2 起 |
| Soak | 3 目标 30 分钟 / 4 小时 | 本地 | M2/M4 |
| Privacy | 网络、落盘、日志脱敏 | 抓包/文件检查/日志抽查 | M1/M4 |
| Release | 干净机器安装、签名、公证 | 手工 | M5 |

## 4. 检测 fixture 要求

M3 建立 `Tests/Fixtures/` 或独立 fixture 目录，每个应用至少：

- 1 条正常流式输出序列（应有 `streaming -> settling -> completed`）；
- 1 条“长停顿但仍在生成”的负例（不得提前 completed）；
- 1 条“完成控件消失/出现”的边界；
- 1 条权限缺失/黑帧序列（应走 unknown 或 error）。

fixture 只存必要的窗口区域帧或哈希指纹；不提交真实对话全文、用户名、密钥。

## 5. 手工验收矩阵

| 场景 | 期望 |
|---|---|
| 首次启动，拒绝屏幕录制 | 明确提示 + 系统设置入口；无崩溃 |
| 授予屏幕录制后选择 1 窗口 | 2 秒内首帧；卡片出现 |
| 3 个目标同时运行 30 分钟 | 卡片不串流；CPU/内存可接受 |
| 目标窗口最小化 | 卡片显示不可见/暂停；不显示旧帧冒充实时 |
| 目标应用退出 | 卡片显示 Window Closed；点击不激活错误应用 |
| 暂停目标 | 状态 PAUSED；最后一帧保留但不刷新；恢复后重新 LIVE |
| 窗口关闭后重新打开 | 同 bundle 唯一窗口时 10 秒级自动重建；多候选保持等待不猜 |
| 连接中立即暂停 | 最终停在 PAUSED，无 CAPTURE ERROR、无残留流 |
| 同一应用两个窗口 | 两张卡片；点击各自切到正确窗口；标题重复时拒绝选择并提示 |
| 目标窗口被其他窗口遮挡 | 捕获是否继续需记录；缩略图不得假装在顶层 |
| 多显示器 / Space 切换 | 状态可恢复；不崩溃 |
| 浅色/深色 | 状态文字可读，不只靠颜色 |
| 窄窗口 600px | 无横向溢出，卡片降为单列；状态条隐藏右侧提示 |
| 900px | 多列卡片与状态条正常，无截断 |
| 拒绝辅助功能权限 | 点击卡片只激活应用并提示授权；捕获/检测不阻塞 |
| 退出 Argus | 捕获停止；无残留进程/帧文件 |
| 抓包/代理 | 无主动外联 |
| 日志抽查 | 不含窗口正文、提示词、邮箱 |

## 6. 性能与稳定性

M4 记录：

- 3 目标 4 小时 CPU 平均值/峰值、内存曲线、帧率、丢帧数。
- 1 目标 2 fps vs 1 fps 的差异。
- OCR 开启/关闭的 CPU 差异。
- 窗口关闭/重开 50 次的恢复情况。
- 显示器休眠/唤醒、锁屏/解锁后的恢复。

建议门槛（草案，M4 实测校准）：

- 3 目标平均 CPU ≤ 8%（Apple Silicon）；
- 内存 ≤ 300 MB；
- 4 小时无崩溃、无持续内存增长；
- 单目标卡顿不影响其他卡片。

## 7. 隐私与安全验收

- 应用运行期间无主动网络请求；若未来有更新检查，必须可关闭。
- 不创建截图文件；临时目录抽查无窗口帧。
- 日志只含目标 id/状态/错误码/耗时；不含正文。
- 捕获帧在目标移除/暂停后释放。
- 受保护/DRM 窗口显示不可捕获，不尝试绕过。

## 8. 发布门禁

M1–M3：

```bash
swift build
swift test
```

M4 额外：

- 手工矩阵通过；
- 4 小时 soak 记录；
- 隐私检查通过；
- 诊断四类错误可复现。

M5 额外：

- 干净机器安装；
- 签名/公证验证；
- 权限 onboarding 从零完成；
- 发布检查单见 `07-发布与分发.md`。

## 9. 不做的事

- 不用 mock 帧宣称完成检测已验证。
- 不在 CI 请求屏幕录制/辅助功能权限。
- 不把真实用户窗口截图提交到仓库。
- 不用“测试全绿”替代真实窗口验收。
