# 07 — 发布与分发

- 版本：v0.1
- 日期：2026-11-21
- 状态：草案；MVP 未到发布阶段

## 1. 阶段

| 阶段 | 对象 | 分发方式 | 前置 |
|---|---|---|---|
| M0–M3 | Owner / 开发 | 本地 `swift run` / Xcode | 无 |
| M4 内部 Alpha | 小范围内部 | 本地构建的 `.app` / 临时包 | 手工矩阵 + 隐私检查 |
| M5 内测 | 受控测试用户 | Developer ID 签名 + 公证 + DMG/ZIP | 发布检查单 |
| 公开 | 待定 | 待定 | 独立决策 |

## 2. 发布形态

- 首版默认 **Developer ID + 公证** 的独立 `.app`，不默认走 Mac App Store。
- 原因：ScreenCaptureKit 与 Accessibility 的权限/沙箱组合需要实测；App Store 审核策略可能限制能力。
- 是否上架 Mac App Store 作为 M5 决策项，不在 M0 拍板。
- MVP 不做自动更新服务；内测可手动替换版本。

## 3. 版本与构建

- 版本：`0.1.0` 起；内部构建号递增。
- Bundle id：`com.bayjf.argus`（待确认，正式签名前锁定）。
- 构建产物不提交仓库；发布包放独立发布目录/Release。
- 每次发布记录：版本、commit、macOS 最低版本、已知限制、回滚方式。

## 4. 首次启动与权限

1. 一句话说明：只观察用户选择的窗口；不联网、不落盘截图。
2. 屏幕录制权限说明与系统设置入口。
3. 窗口选择器；选择后创建卡片。
4. 辅助功能权限按需请求；拒绝时明确降级。
5. 权限状态变化可热更新，不要求重启。

## 5. 发布检查单

- [ ] `swift build` / `swift test` 通过。
- [ ] M4 手工矩阵通过，附证据。
- [ ] 4 小时 3 目标 soak 通过。
- [ ] 无主动外联；无截图落盘；日志脱敏。
- [ ] 干净机器安装、首次启动、权限拒绝/授予路径通过。
- [ ] 签名/公证通过；Gatekeeper 无异常。
- [ ] 版本号、Bundle id、最低 macOS 版本正确。
- [ ] 已知限制写入发布说明（支持的应用、检测准确率、权限要求）。
- [ ] 回滚包与卸载说明就绪。

## 6. 落地页与公共入口

- **MVP 不建 `argus-landing`，不新增 `argus.bayjf.com` 子域。**
- 公共入口使用 BayJF 的 `/products/argus` 与 `/zh/products/argus` 产品页/案例页。
- 产品页内容：产品定位、真实截图/演示、支持的目标应用、权限说明、下载/获取方式、已知限制。
- 在 M0–M3 没有真实界面证据前，不发布营销页，不写“已支持”列表。
- M4 内部 Alpha 后复核：若出现独立品牌需求/外部合作/独立下载页需求，再开 ADR 评估 `argus-landing`。
- 长期默认仍留在 BayJF 产品页；拆独立子域需同时满足至少 3 项：公开下载/更新/支持页承载不了、独立品牌或合作需求、持续 SEO 内容、能独立维护子域与法务页。
- 若拆分：`argus-landing` 独立仓 + Cloudflare Pages + `argus.bayjf.com`；BayJF `/products/argus` 保留为案例页，两处不复制同一篇正文。

## 7. 支持与反馈

- 反馈入口：GitHub Issue（公开仓库）或 owner 指定渠道。
- 诊断信息：本地导出脱敏文本；不附带截图。
- 安全问题：不公开披露窗口内容；走私下渠道。

## 8. 不承诺

- 不承诺对所有 AI 客户端都准确检测完成。
- 不承诺 Windows 时间表。
- 不承诺云端/跨设备能力。
- 不承诺 App Store 上架时间。
