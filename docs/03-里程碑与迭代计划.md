## 2. M0 — 仓库骨架（已完成）

### 范围

- Swift Package：`ArgusCore` + `Argus` executable + tests。
- SwiftUI Dashboard mock 卡片。
- `ReplyCompletionDetector` 状态机。
- PRD、架构、里程碑、功能点、ADR、测试、发布、风险文档。
- 公开 GitHub 仓库与 `main` / `dev` 分支。

### 退出条件

- `swift build` 通过。
- `swift test` 7 tests / 0 failures。
- 文档索引能从一个入口找到全部文档。
- 没有把 mock 写成真实捕获。

### 已知不完整

- 没有 ScreenCaptureKit 实现。
- 没有权限引导。
- 没有真实窗口切换。
- 没有 `.app` 包、签名或公证。

## 3. M1 — 单目标捕获

### 范围

- `SCShareableContent` 窗口枚举与窗口选择器。
- 屏幕录制权限引导与状态热更新。
- 单个 `WindowCaptureSession`：2 fps，960 宽比例缩略图。
- 一张真实监控卡片；显示真实窗口标题与帧时间。
- 目标关闭/权限拒绝的失败状态；窗口关闭通过 `CGWindowList` 复核。
- 正式 `.app` 运行方式的最小验证（可以先用 Xcode 本地运行）。

### 退出条件

- 选择一个真实窗口后 2 秒内出现首帧。
- 窗口内容变化后 1 秒内缩略图更新。
- 拒绝屏幕录制权限时无崩溃，有系统设置入口。
- `swift build && swift test` 通过；新增单元测试不依赖真实窗口。

### 风险

- ScreenCaptureKit 权限/TCC 行为因系统版本不同。
- Swift Package executable 不是完整 `.app`，权限与 Info.plist 可能受限；M1 需要补 app bundle 方案。

## 4. M2 — 多目标 Dashboard 与切换

### 范围

- `CaptureCoordinator` 管理多个目标，目标独立启停。
- 卡片网格、状态、帧新鲜度、暂停/恢复/移除。
- 点击缩略图激活目标窗口；多窗口匹配。
- 目标列表本地持久化与重启解析。
- 资源上限与基础背压。

### 切片与进度

| 切片 | 范围 | 状态 |
|---|---|---|
| M2a 持久化与上限 | `PersistedTarget` / `TargetFile` / `TargetFileStore` / `TargetRestorer`；硬上限 3；`NEEDS WINDOW` 与「Re-select window」；`targetID` 与轮询枚举修正 | 已完成 2026-11-21（三目标重启恢复、多窗口不猜） |
| M2b 点击切换 | `AccessibilityWindowActivator`、`WindowMatchPolicy`、辅助功能权限独立流程、失败/降级提示 | 已完成 2026-11-21（AX 精确切窗、重复标题不猜） |
| M2c 生命周期与稳定性 | `paused`/`windowClosed` 状态、暂停/恢复、10 秒严格重建循环、竞态守卫、600px 布局、`scripts/soak.sh` | 已完成 2026-11-21（30 分钟 soak、600/900 深浅色） |

### 退出条件

- 3 个目标同时捕获 30 分钟，无串流/错绑。
- 点击切换 90% 在 1.5 秒内到正确窗口。
- 目标退出/窗口关闭有明确状态。
- 900px 与 600px 宽度下无横向溢出；浅色/深色可读。

## 5. M3 — 回复完成检测 v1

### 范围

- 视觉帧差 + Vision OCR 文本指纹。
- Accessibility 信号（可选权限）与 Stop 控件检测。
- Target Profile：ROI、控件特征、settleDuration。
- fixture 集：至少 3 个应用 × 正例/负例。
- UI 显示 `Streaming / Settling / Completed / Unknown` 与最近状态时间。

### 切片与进度

| 切片 | 范围 | 状态 |
|---|---|---|
| M3a 核心模型与状态机 | `ReplyObservation`、`ReplyProfile`、`LumaGrid`、`ReplyCompletionDetector` 的 settling 重开/unknown 历史/`phaseChangedAt` | 已完成 2026-11-22（48 个 ArgusCoreTests 全通过，其中 13 个状态机用例） |
| M3b 信号提取 | `ReplySignalAnalyzer`、Vision OCR 哈希、OCR 节流、`AXStopControlProbe` | 已完成 2026-11-22（3 目标实机运行） |
| M3c Dashboard 接入 | 每目标 detector/analyzer、0.25 秒取帧、0.5 秒检测调度、暂停/移除/关窗清理、State/Frame footer | 已完成 2026-11-22（Streaming/Settling/Completed 同屏可见） |
| M3d fixture 验收 | 自建合成 chat fixture（A/B/C 三个 bundle）、正例、stall、stallAx、static、blink、0.1 秒相位采样 | 已完成 2026-11-22（正负两轮通过；证据见 handoff） |
| M3e 真实客户端标定 | ChatGPT / Claude / Cursor 等的 ROI、control ROI、settle、阈值 | 已完成 2026-11-22（M3 范围：豆包工作视觉 Profile；ChatGPT/Claude/Cursor 延后 M4） |
| M3f 收口 | 文档、提交、push、清理 fixture | 已完成 2026-11-22（`941cc69`/`f342fdf`/`1bfed2d`；豆包 Profile `335edbc`/`dcb201b`；PR #9/#10 已合入 `main`） |

### 退出条件

- fixture 集达到 PRD §9 草案指标，或 owner 接受调整后的阈值。
- 不出现“明显还在生成却显示 Completed”的高置信误判。
- 权限缺失时降级为视觉检测，不崩溃。
- 状态机单测覆盖所有转换。

M3 验收证据：合成 fixture 正例完成上界 A 2.072 s / B 1.865 s / C 2.220 s；`stallAx` 4.002 s 内始终 `Streaming`；`static`/`blink` 全程 `Idle`，均未 `Completed`。豆包工作真实客户端视觉链路：`Idle → Streaming → Settling → Completed`，Settling→Completed 1.07 s，完成后 30 s+ 保持 `Completed`；静态会话 11.9 s 全程 `Idle`。豆包工作的 AX 增强不可用（Chromium Web 内容不暴露 Stop），ChatGPT/Claude/Cursor 标定延后 M4。

### 风险

- OCR 对动画光标/闪烁 UI 敏感。
- 不同客户端“停止生成”控件形态差异大。
- 完成判定没有 ground truth，需要人工标注。

## 6. M4 — 内部 Alpha

### 范围

- 4 小时多目标 soak。
- CPU/内存上限、帧队列背压、异常恢复。
- 诊断页与脱敏导出。
- 隐私检查：无网络、无截图落盘、日志不含正文。
- 4 个目标以内的稳定性；超出上限的产品行为。
- 目标应用矩阵的手工验收。
- AX 增强路径：WebView/纯图标 Stop 的 Accessibility 桥或视觉模板；ChatGPT/Claude/Cursor 的 Profile 标定。

### 退出条件

- 4 小时 3 目标无崩溃/无内存持续增长。
- 无主动外联；日志抽查无正文。
- 四类错误可诊断：无帧 / 无权限 / Unknown / 激活失败。
- 形成一份 Alpha 验收记录。

## 7. M5 — 内测分发

### 范围

- 正式 `.app`、Developer ID 签名、公证、DMG/ZIP。
- 首次启动权限 onboarding。
- 版本号、更新策略（MVP 可手动更新）。
- 支持文档与反馈入口。
- 是否上架 Mac App Store 的决策。

### 退出条件

- 干净机器可安装并完成首次配置。
- Gatekeeper/公证通过。
- 权限拒绝/授予路径可完成。
- 发布检查单全部通过。

## 8. 依赖与顺序

```text
M0 ──> M1 ──> M2 ──> M3 ──> M4 ──> M5
          │       │
          └─ 权限 └─ 窗口身份/切换
```

- M1 的 app bundle 方案会影响权限与分发，必须尽早验证。
- M3 依赖 M1/M2 的真实帧与目标窗口；不要在 mock 上直接调阈值。
- M5 的签名/公证不阻塞 M1–M4 的开发，但需要提前准备凭证。

## 9. 暂不做

- Windows 迁移。
- 云端同步/远程监控。
- App Store 上架（先作为 M5 的决策项）。
- 自动更新服务（MVP 可手动）。
- 插件/脚本系统。
